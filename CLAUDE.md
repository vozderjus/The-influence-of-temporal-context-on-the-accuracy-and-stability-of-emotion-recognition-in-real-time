# CLAUDE.md

Контекст для Claude Code. Пользователь работает с разных устройств (ПК, ноутбук, телефон),
поэтому весь контекст между сессиями хранится **в репозитории**, а не в памяти сессии.

## Начало каждой сессии
1. Прочитать `docs/PROGRESS.md` — там текущее состояние ветки, что сделано и что осталось.
2. Проверить `git status` и `git log --oneline -10` на текущей ветке.

## Конец каждой сессии (обязательно)
Обновить `docs/PROGRESS.md`: что сделано в этой сессии, что не проверено, следующие шаги.
Добавить запись в раздел «Журнал сессий» с датой. Закоммитить вместе с изменениями кода.

## О проекте
Исследование: влияние временного контекста (трекинг лиц + причинное сглаживание предсказаний:
скользящее среднее, EMA) на точность, стабильность и задержку распознавания эмоций
в видеопотоке реального времени. Сравнение с покадровой классификацией.
Цель и исследовательские вопросы — в `README.md`.

## Ветки
- `main` — только README.
- `emotion_recognition` — исходный модуль `emotion_detection.py` (DeepFace по пути к файлу).
- `Ivn_Chel` — рабочая ветка пользователя (форк `emotion_recognition`). Работать здесь.

## Соглашения по коду
- Кадры и вырезки лиц передаются в формате **numpy BGR** (как в OpenCV).
- Классы эмоций — ровно 6, порядок из `emotion_detection.EMOTIONS`:
  `angry, disgust, fear, happy, sad, neutral`. `surprise` отбрасывается, вероятности перенормируются (сумма = 100).
- Единая точка распознавания — `emotion_detection.get_emotions(image, model, is_face_crop)`;
  формат ответа `{'emotions', 'dominant_emotion', 'inference_time'}` менять нельзя
  (на него завязан код ветки `emotion_recognition`).
- Модули без зависимости от Streamlit (`emotion_detection`, `face_detection`, `visualization`, `report`)
  должны оставаться пригодными для офлайн-экспериментов на CREMA-D.
- Комментарии и тексты интерфейса — на русском.

## Окружение
- Python 3.10/3.11 (TensorFlow не поддерживает 3.13+). Виртуальное окружение — `.venv/`.
- Датасет: `artifacts/CREMA-D-small/` (не в git). Медиа в Git LFS — по умолчанию там заглушки.
