🎭 Инструкция по запуску Emotion Project

Пошаговая инструкция для Windows, macOS и Linux

Что нужно передать

Проект берётся из git-репозитория (ветка Ivn_Chel). Нужны все .py-файлы из корня и requirements.txt:

Файл Что это
app.pyИнтерфейс Streamlit (точка входа)
emotion_detection.pyРаспознавание эмоций (DeepFace / ViT)
face_detection.pyПоиск лиц (BlazeFace)
visualization.pyРамки, подписи, цвета
report.pyPDF-отчёт
requirements.txtСписок библиотек Python
Модель blaze_face_short_range.tflite передавать не нужно — она скачивается автоматически в папку models/ при первом запуске.
Папку venv тоже не отправлять — она создаётся заново на каждом компьютере.
1

Установить Python

Windows

  1. Открыть сайт python.org/downloads
  2. Скачать Python 3.10 или 3.11 (не 3.13 — могут быть проблемы с TensorFlow)
  3. Запустить установщик
  4. Обязательно поставить галочку «Add Python to PATH» на первом экране
  5. Нажать «Install Now»
⏱ ~1–2 минуты

macOS

  1. Открыть Терминал (Cmd+Пробел → набрать «Terminal»)
  2. Ввести: python3 --version
  3. Если Python не установлен — скачать с python.org/downloads

Linux

Python обычно уже установлен. Проверить: python3 --version. Если нет:

sudo apt update && sudo apt install python3 python3-pip python3-venv
2

Подготовить папку проекта

⚠️ Важно: НЕ размещать в облачных папках!
Папка проекта не должна находиться в: OneDrive, Google Drive, Dropbox, iCloud.
Облачные сервисы мешают установке библиотек Python и вызывают ошибки.

Где создать папку

  • Windows: C:\Projects\emotion_project\
  • macOS: ~/Projects/emotion_project/
  • Linux: ~/Projects/emotion_project/

Склонировать репозиторий в эту папку (или скопировать в неё файлы проекта).

3

Открыть терминал в папке проекта

Windows — 3 способа

Способ 1 (самый простой): Открыть папку C:\Projects\emotion_project в Проводнике → щёлкнуть в адресной строке (там где написан путь) → написать cmd → нажать Enter.

Способ 2: Нажать Win+R → написать cmd → нажать Enter. Затем ввести:

cd C:\Projects\emotion_project

Способ 3: В поиске Windows набрать «cmd» или «Командная строка» → открыть → ввести cd C:\Projects\emotion_project

macOS

Открыть Терминал (Cmd+Пробел → «Terminal») → ввести:

cd ~/Projects/emotion_project

Linux

Открыть терминал (Ctrl+Alt+T) → ввести:

cd ~/Projects/emotion_project
4

Создать виртуальное окружение

Виртуальное окружение — изолированная среда для библиотек проекта, чтобы они не конфликтовали с другими программами.

Windows

python -m venv venv

Если ошибка «python не найден» — попробовать python3 -m venv venv или py -m venv venv.

Затем активировать:

venv\Scripts\activate

В начале строки появится (venv) — это значит окружение активно. ✅

macOS / Linux

python3 -m venv venv
source venv/bin/activate
⏱ ~10–30 секунд
5

Установить библиотеки

Убедиться, что в терминале виден (venv) в начале строки. Ввести:

pip install -r requirements.txt
⏱ от 5 до 20 минут (зависит от скорости интернета) 📦 ~3–5 ГБ (TensorFlow, PyTorch и др.)
Во время установки будут идти строки с загрузкой — это нормально. Дождаться, пока снова появится приглашение командной строки (venv) C:\...>.

Жёлтые предупреждения (warnings) — можно игнорировать.
Красные ошибки (errors) — нельзя, см. раздел «Решение проблем».
6

Запустить приложение

streamlit run app.py
⏱ Первый запуск: 2–5 минут (загрузка моделей нейросетей)

После запуска в терминале появится:

Local URL: http://localhost:8501

Браузер откроется автоматически. Если не открылся — скопировать адрес http://localhost:8501 и вставить в браузер.

Не закрывать терминал пока работаете с приложением! Терминал — это сервер, без него сайт не работает.
✦

Повторный запуск (каждый следующий раз)

Каждый раз при запуске нужно выполнить только 3 команды:

Windows

cd C:\Projects\emotion_project
venv\Scripts\activate
streamlit run app.py

macOS / Linux

cd ~/Projects/emotion_project
source venv/bin/activate
streamlit run app.py
Устанавливать библиотеки повторно не нужно. Шаги 1–5 делаются только один раз.

🔧 Решение проблем

«python не найден» или «python is not recognized»

Python не добавлен в PATH. Решение: переустановить Python, на первом экране установщика поставить галочку «Add Python to PATH». Попробовать также python3 или py вместо python.

ImportError: cannot import name 'pipeline' from 'transformers'

Самая частая причина — папка проекта находится в OneDrive или другом облачном хранилище. Решение:

  1. Создать новую папку (например C:\Projects\emotion_project)
  2. Скопировать туда файлы проекта
  3. Удалить старый venv
  4. Повторить шаги 3–6 заново

pip install зависает или выдаёт ошибки

Проверить интернет-соединение. Попробовать:

pip install --upgrade pip

и повторить установку. На macOS/Linux может потребоваться:

pip install --break-system-packages -r requirements.txt

Браузер не открывается

Вручную открыть http://localhost:8501 в любом браузере (Chrome, Firefox, Edge).

Ошибка с .tflite файлом

Модель скачивается в models/blaze_face_short_range.tflite при первом запуске — нужен интернет. Если скачивание прервалось, удалить папку models/ и запустить снова.

Квадратики вместо русских букв

Отсутствует подходящий шрифт. На Linux установить:

sudo apt install fonts-dejavu

На macOS и Windows шрифты уже встроены — проблема обычно не возникает.

Веб-камера не работает

  • Разрешить доступ к камере в браузере (всплывающее окно при первом использовании)
  • Закрыть другие программы, которые используют камеру (Zoom, Skype, Teams)
  • Попробовать другой браузер (Chrome работает лучше всего)
